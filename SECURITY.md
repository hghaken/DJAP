# Security Policy

## Supported versions

Only the latest release of DJAP (DJ Audio Processor) receives security fixes. The current latest release is [0.1.362](https://github.com/hghaken/DJAP/releases/tag/v0.1.362). Older versions are not supported.

## Reporting a vulnerability

Please report security issues privately with GitHub's **Report a vulnerability** button under the Security tab, or use this link:

https://github.com/hghaken/DJAP/security/advisories/new

Do not open a public issue for a vulnerability.

Include:

- The DJAP version
- Your Windows version
- The host or DAW, if the report is about the VST3 plugin
- Steps to reproduce

## What to expect

DJAP is a hobby project maintained by one person. The aim is to acknowledge reports within about 7 days. There is no guaranteed timeline for a fix.

If a vulnerability is fixed, it will be credited in the release notes if you want that.

## Scope

This policy covers the DJAP standalone application and the VST3 plugin. Third-party drivers (ASIO and others) and host software are out of scope.
